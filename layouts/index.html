Simulation Rules 模拟盘规则

目标仓位按重点机构信号分配，最多保留 {{ $sim.meta.max_positions }} 个持仓。

买卖每周最多 {{ $sim.meta.rebalance_step.rebalance_step_weight_pct }}% 组合权重；买入缺口低于 {{ $sim.meta.rebalance_step.min_buy_gap_weight_pct }}% 跳过，卖出可清尾仓。

历史回测只使用当时已披露 13F 和当日价格，结果仅用于研究观察。
