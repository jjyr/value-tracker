# Value Tracker Frontend Layout v0.1

## 1. 首页定位

首页不是单个榜单页，而是一个“机构信号驾驶舱”。打开后第一屏先看到模拟盘表现、当日变化、当前持仓和最近调仓，然后再向下看多个榜单的展开摘要。

MVP 不做单个榜单独立视图。多个榜单在首页展开显示，每个榜单展示 Top N 摘要。

## 2. 首页结构

### 2.1 顶部信息栏

高度保持紧凑，展示：

- 产品名：`价值追踪`
- 数据日期
- 最新 13F 报告期
- 最后构建时间
- 数据质量状态，例如 `OK`、`STALE`、`PARTIAL`

### 2.2 第一屏：模拟盘总览

第一屏由三块组成。

左侧：模拟盘收益卡片

- 当前净值
- 累计收益
- 本周收益
- YTD 收益
- 最大回撤
- 现金占比
- 与 `SPY`、`QQQ` 的差值

中间：净值曲线

- 模拟盘净值
- `SPY`
- `QQQ`
- 时间范围切换：`1M`、`3M`、`YTD`、`ALL`

右侧：今日/最近再平衡摘要

- 最近再平衡日期
- 买入列表
- 卖出列表
- 卖出原因，例如 `机构卖出榜 Top 10`
- 本次候选数量
- 本次持仓数量

### 2.3 当前持仓区

以表格展示当前模拟盘持仓。

字段：

- 股票
- 公司名
- 权重
- 当前价格
- 入场价格
- 持仓收益
- 评分
- 买入榜 Top 10 是否命中
- 持有榜 Top 10 是否命中
- 是否低于机构平均持有价格
- 是否重点机构买入
- 是否进入卖出榜 Top 10

表格默认按权重降序。

### 2.4 调仓记录区

展示最近 10 次调仓。

字段：

- 日期
- 动作：买入 / 卖出 / 调整权重 / 继续持有
- 股票
- 原权重
- 新权重
- 价格
- 原因

### 2.5 机构综合榜区

首页展示一个机构综合榜，不跳转独立榜单页。

榜单排序：

```text
total_tracked_value_usd desc
holders_count desc
symbol asc
```

买入、卖出、新建仓、清仓、重点机构等信号以标签展示，例如 `买入 #1`、`卖出 #2`、`新建仓 #1`、`清仓 #1`、`已清仓`、`段永平`、`李录`。持有榜本身已按持有市值排序，不额外展示 `持有 #1` 标签。不同类型标签使用不同颜色。已被追踪机构全部清仓的股票仍进入综合榜，持有市值为 `0`，并标记 `已清仓`。

综合榜默认展示 Top 10，支持展开到 Top 100。

每行字段：

- 排名
- 股票
- 公司名
- 信号标签
- 价格 / 当日涨跌
- 市值
- PE / Forward PE / PS
- 买入机构：`11 / 200`
- 卖出机构：`22 / 200`
- 持有机构：`38 / 200`
- 对应榜单主排序金额，例如买入金额、卖出金额、持有金额

### 2.6 股票详情入口

点击股票行打开股票详情页。

详情页优先展示：

1. 股票基本信息和标签。
2. 机构信号摘要。
3. 机构明细表。
4. 估值和价格走势。
5. 榜单历史。
6. 公开披露事件。

## 3. 视觉设计原则

- 偏金融终端和研究工具，不做营销式首页。
- 信息密度高，但分区清楚。
- 使用表格、紧凑卡片、可展开区域。
- 避免大面积装饰图和过重渐变。
- 关键数字用单色强调，涨跌用红/绿或本地约定颜色。
- 对 `11 / 200` 这类指标提供 tooltip：`200 家追踪机构中有 11 家本期买入`。

## 4. 首页默认顺序

```text
顶部信息栏
模拟盘总览
当前持仓
最近调仓记录
机构综合榜
页脚风险提示
```

## 5. 失败默认值策略

默认值分成两类：展示默认值和计算默认值。

### 5.1 展示默认值

用于前端展示，不参与排序和回测。

| 数据 | 展示 |
|---|---|
| 缺失数字 | `--` |
| 缺失百分比 | `--` |
| 缺失日期 | `--` |
| 缺失标签 | 空数组 |
| 缺失解释文案 | 不展示该区域 |

### 5.2 计算默认值

用于指标计算、榜单和回测。原则：不伪造关键市场数据。

| 数据 | 处理 |
|---|---|
| 机构计数缺失 | 默认 `0`，并记录 data quality issue |
| 机构金额缺失 | 默认 `0`，并记录 data quality issue |
| 当前价格缺失 | 不进入当期榜单和模拟盘 |
| 市值缺失 | 显示为 `--` |
| PE / Forward PE / PS 缺失 | 显示为 `--` |
| 机构平均持有价格缺失 | 不进入模拟盘候选 |
| 市场数据抓取失败 | 优先使用最近成功快照，并标记 `is_stale=true` |
| 最近成功快照超过 `max_stale_days` | 不进入榜单和模拟盘 |

### 5.3 构建失败

- 如果抓取或构建失败，不发布半成品。
- 保留上一版静态站点。
- 在下一次成功构建时显示最新状态。
- 构建失败写入 `build_runs` 和 `data_quality_issues`。

## 6. 风险提示位置

首页底部、模拟盘区域和股票详情页都展示简短提示：

```text
本页面仅用于研究和信息展示，不构成投资建议。13F 数据存在披露延迟，机构持仓变化不代表当前仍然持有。模拟盘为历史回测，不代表未来收益。
```
